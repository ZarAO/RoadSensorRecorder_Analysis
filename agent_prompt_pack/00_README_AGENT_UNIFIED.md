# 00 — README для GitHub Copilot (UNIFIED)

Цей `agent_prompt_pack` — **самодостатній** набір інструкцій для GitHub Copilot (VS Code), щоб він:
1) проаналізував поточний код репозиторію,
2) відрефакторив пайплайн під вимоги книги,
3) реалізував **обов’язкові методи/формули з книги** (IRI з PSD та мультиваріантну регресію),
4) додав **orientation-корекцію** (обов’язково для цього проєкту),
5) додав **vehicle classification** в рамках того, що реально описано в книзі (LEV/DSD + параметри Stif/DampF/TyreS/Npeop),
6) зробив **100 м сегментацію** як у книзі,
7) випустив відтворювані артефакти (CSV/GeoJSON/HTML map/plots/report).

## Головні правила для агента
- **НЕ** використовуй інтернет/браузинг/зовнішні джерела.
- **НЕ** “вигадуй” формули з книги: все, що є “Book Canon”, взято в `02_FORMULAS_TEST_MAP_UNIFIED.md`.
- Дозволено: реалізовувати інженерні деталі, яких книга не дає як формул (наприклад, математично коректну orientation-корекцію), але:
  - чітко позначай це як **Engineering Addition**,
  - не підміняй ними формули з книги,
  - забезпеч тестами.

## Що вважається успіхом
- Пайплайн видає **IRI (m/km)** по **100 м сегментах** (мінімум через PSD-модель та Eq.6).
- Є конфігурація **vehicle_type**: `LEV`, `DSD`, `GENERIC` і використання Eq.4/5/6 відповідно (книга).
- Є **orientation-корекція**, щоб:
  - вертикальна складова була в “world” координатах,
  - горизонтальна перпендикулярна до напрямку руху (для ML/дефектів).
- Є “sampling compliance report” згідно вимог книги (fs та dx≤300 мм).
- `python main.py` не зламаний (legacy шлях працює), але новий пайплайн — основний.

## Як використовувати в VS Code
1) Відкрий репозиторій.
2) Відкрий `05_PROMPT_TO_PASTE_UNIFIED.md` → скопіюй PROMPT і встав у Copilot Chat.
3) Далі агента не направляй “на слово”: перевіряй по `04_ACCEPTANCE_CHECKLIST_UNIFIED.md`.

Файли:
- `01_PLAN_STRUCTURE_UNIFIED.md` — покрокова інструкція з задачами.
- `02_FORMULAS_TEST_MAP_UNIFIED.md` — **формули/коефіцієнти/таблиці з книги** + інженерна математика для orientation.
- `03_METHODS_AND_FLAGS_UNIFIED.md` — конфіг/CLI/прапорці.
- `04_ACCEPTANCE_CHECKLIST_UNIFIED.md` — критерії приймання.
- `05_PROMPT_TO_PASTE_UNIFIED.md` — “один промпт”, який стартує роботу агента.
