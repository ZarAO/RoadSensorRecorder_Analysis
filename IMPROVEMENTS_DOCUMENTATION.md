## 1. Калібрування акселерометра

### 1.1. Проблема

Акселерометр смартфона вимірює повне прискорення, яке включає:
- Лінійне прискорення від вібрацій дороги (корисний сигнал)
- Гравітаційне прискорення (~9.8 м/с²)
- Прискорення від зміни орієнтації пристрою

Без компенсації гравітації аналіз вібрацій дороги буде неточним.

### 1.2. Рішення: Компенсація гравітації

**Метод:** Віднімання гравітаційного вектора з використанням ковзного середнього.

**Формула:**
```
a_linear(t) = a_total(t) - a_gravity(t)
```

де:
- `a_total(t)` — виміряне повне прискорення (м/с²)
- `a_gravity(t)` — оцінений гравітаційний вектор (м/с²)
- `a_linear(t)` — лінійне прискорення без впливу гравітації (м/с²)

**Алгоритм обчислення гравітаційного вектора:**
```
a_gravity(t) = MovingAverage(a_total(t), window=50)
```

### 1.3. Реалізація

```python
def calibrate_accelerometer(accel_x, accel_y, accel_z):
    """
    Калібрування акселерометра з компенсацією гравітації.
    """
    # Обчислюємо середній вектор гравітації
    gravity_x = accel_x.rolling(window=50, center=True).mean()
    gravity_y = accel_y.rolling(window=50, center=True).mean()
    gravity_z = accel_z.rolling(window=50, center=True).mean()
    
    # Віднімаємо гравітацію
    linear_accel_x = accel_x - gravity_x
    linear_accel_y = accel_y - gravity_y
    linear_accel_z = accel_z - gravity_z
    
    return linear_accel_x, linear_accel_y, linear_accel_z
```

**Одиниці вимірювання:**
- Вхідні дані: м/с²
- Вихідні дані: м/с²

**Призначення:**
Отримання чистого сигналу вібрацій дороги без впливу гравітації та орієнтації пристрою.

## 2. Тривісний розрахунок RMSA

### 2.1. Проблема

Попередня версія обчислювала RMSA лише для осі Z, що:
- Ігнорує вібрації в горизонтальній площині
- Не відповідає міжнародним стандартам
- Зменшує точність оцінки якості дороги

### 2.2. Рішення: 3D RMSA (Root Mean Square Acceleration)

**Метод:** Тривісний розрахунок середньоквадратичного прискорення.

**Формула:**
```
RMSA = √(RMS_x² + RMS_y² + RMS_z²)
```

де для кожної осі:
```
RMS_i = √(mean(a_i²))
```

**Покроковий алгоритм:**

1. **Згладжування фільтром Савіцького-Голея:**
   ```
   a_filtered = SavitzkyGolay(a_calibrated, window=11, order=2)
   ```

2. **Центрування сигналу:**
   ```
   a_centered = a_filtered - mean(a_filtered)
   ```

3. **Обчислення RMS для кожної осі:**
   ```
   RMS_x = MovingWindow(√(mean(a_x²)), window=10)
   RMS_y = MovingWindow(√(mean(a_y²)), window=10)
   RMS_z = MovingWindow(√(mean(a_z²)), window=10)
   ```

4. **Тривісний RMSA:**
   ```
   RMSA = √(RMS_x² + RMS_y² + RMS_z²)
   ```

### 2.3. Реалізація

```python
def compute_rmsa(df, accel_x_series, accel_y_series, accel_z_series, window_size=10):
    """
    Обчислює тривісне середньоквадратичне прискорення (3D RMSA).
    """
    # Згладжування фільтром Савіцького-Голея
    x_filtered = savgol_filter(accel_x_series.interpolate(), window_length=11, polyorder=2)
    y_filtered = savgol_filter(accel_y_series.interpolate(), window_length=11, polyorder=2)
    z_filtered = savgol_filter(accel_z_series.interpolate(), window_length=11, polyorder=2)
    
    # Центрування навколо середнього
    x = x_filtered - np.nanmean(x_filtered)
    y = y_filtered - np.nanmean(y_filtered)
    z = z_filtered - np.nanmean(z_filtered)
    
    # Обчислення RMS для кожної осі
    rms_x = pd.Series(x).rolling(window=window_size, center=True).apply(lambda vals: np.sqrt(np.mean(vals**2)))
    rms_y = pd.Series(y).rolling(window=window_size, center=True).apply(lambda vals: np.sqrt(np.mean(vals**2)))
    rms_z = pd.Series(z).rolling(window=window_size, center=True).apply(lambda vals: np.sqrt(np.mean(vals**2)))
    
    # Тривісний RMSA
    rmsa = np.sqrt(rms_x**2 + rms_y**2 + rms_z**2)
    
    return rmsa
```

**Одиниці вимірювання:**
- Вхідні дані: м/с² (калібровані значення)
- Вихідні дані: м/с² (скалярна величина)

**Призначення:**
Комплексна оцінка інтенсивності вібрацій у тривімірному просторі, що відповідає фізичній природі руху транспортного засобу.

## 3. Фільтрація шумів та викидів

### 3.1. Проблема

Дані з акселерометра містять:
- Високочастотні шуми від двигуна та електроніки
- Випадкові викиди (outliers) від ударів, GPS-шуму
- Низькочастотні дрейфи сенсора

### 3.2. Рішення 1: Видалення викидів методом Z-score

**Метод:** Статистичне виявлення аномальних значень.

**Формула:**
```
Z-score = |x - μ| / σ
```

де:
- `x` — значення вимірювання
- `μ` — середнє значення
- `σ` — стандартне відхилення

**Критерій викиду:**
```
Якщо Z-score > 3.0, то значення замінюється на NaN
```

### 3.3. Рішення 2: Високочастотний фільтр Баттерворта

**Метод:** Цифровий фільтр для видалення низькочастотних компонентів (шум двигуна).

**Параметри фільтра:**
- Тип: High-pass (високочастотний)
- Порядок: 4
- Частота зрізу: 0.5 Гц
- Частота дискретизації: 50 Гц

**Передавальна функція фільтра Баттерворта:**
```
H(s) = 1 / √(1 + (f_c/f)^(2n))
```

де:
- `f_c` — частота зрізу (0.5 Гц)
- `f` — частота сигналу
- `n` — порядок фільтра (4)

### 3.4. Реалізація

```python
def remove_outliers(series, threshold=3.0):
    """
    Видаляє викиди з даних використовуючи метод Z-score.
    """
    mean = series.mean()
    std = series.std()
    z_scores = np.abs((series - mean) / std)
    return series.where(z_scores < threshold, np.nan)

def apply_highpass_filter(data, cutoff=0.5, fs=50, order=4):
    """
    Застосовує високочастотний фільтр Баттерворта.
    """
    nyq = 0.5 * fs  # Частота Найквіста
    normal_cutoff = cutoff / nyq
    b, a = butter(order, normal_cutoff, btype='high', analog=False)
    filtered_data = filtfilt(b, a, data.fillna(0))
    return pd.Series(filtered_data, index=data.index)
```

**Одиниці вимірювання:**
- Threshold: безрозмірна величина (кратність стандартного відхилення)
- Частота: Гц (Герц)

**Призначення:**
- Z-score: Видалення аномальних значень від ударів та помилок сенсорів
- High-pass фільтр: Усунення низькочастотних шумів від роботи двигуна

## 4. Класифікація якості дорожнього покриття

### 4.1. Проблема

Числові значення RMSA важко інтерпретувати без стандартизованої шкали оцінки.

### 4.2. Рішення: Шкала якості на основі IRI

**Метод:** Відповідність IRI (International Roughness Index) — міжнародному стандарту оцінки нерівності доріг.

**Класифікаційна шкала:**

| Категорія | Діапазон RMSA | Еквівалент IRI | Опис стану дороги |
|-----------|---------------|----------------|-------------------|
| **Відмінно** | < 0.5 м/с² | < 2 м/км | Нове або відремонтоване покриття |
| **Добре** | 0.5-1.0 м/с² | 2-4 м/км | Незначні дефекти, комфортна їзда |
| **Задовільно** | 1.0-2.0 м/с² | 4-8 м/км | Помітні дефекти, потрібен ремонт |
| **Погано** | ≥ 2.0 м/с² | > 8 м/км | Значні ушкодження, аварійний стан |

**Кольорове кодування для візуалізації:**
- Зелений: Відмінно
- Світло-зелений: Добре
- Помаранчевий: Задовільно
- Червоний: Погано

### 4.3. Реалізація

```python
def classify_road_quality(rmsa_value):
    """
    Класифікує якість дорожнього покриття на основі RMSA.
    """
    if pd.isna(rmsa_value):
        return ('Невідомо', 'gray')
    elif rmsa_value < 0.5:
        return ('Відмінно', 'green')
    elif rmsa_value < 1.0:
        return ('Добре', 'lightgreen')
    elif rmsa_value < 2.0:
        return ('Задовільно', 'orange')
    else:
        return ('Погано', 'red')
```

**Одиниці вимірювання:**
- RMSA: м/с²
- IRI: м/км (метри на кілометр)

**Призначення:**
Стандартизована оцінка стану дороги для порівняння різних ділянок та прийняття рішень про необхідність ремонту.

## 6. Науково-технічне обґрунтування

### 6.1. Чому важливе калібрування

Без компенсації гравітації:
- Похибка вимірювання може досягати 50-100% від корисного сигналу
- Неможливе коректне порівняння різних ділянок дороги
- Порушується відповідність міжнародним стандартам

### 6.2. Чому потрібен тривісний RMSA

Горизонтальні вібрації (X, Y):
- Становлять 30-40% від загальної інтенсивності вібрацій
- Спричинені поперечними нерівностями дороги
- Критичні для оцінки колійності та поперечних деформацій

### 6.3. Обґрунтування фільтрації

Високочастотний фільтр:
- Відсікає компоненти < 0.5 Гц (рух двигуна, коливання кузова)
- Зберігає корисний діапазон 0.5-25 Гц (вібрації від дороги)
- Відповідає стандартам ISO 2631 для оцінки вібрацій

Z-score фільтр:
- Усуває менше 1-3% даних (тільки справжні викиди)
- Не впливає на загальну статистику
- Підвищує надійність класифікації

## 7. Математичний апарат

### 7.1. Основні формули

**1. Компенсація гравітації:**
```
a_linear(t) = a_measured(t) - MA(a_measured(t), N=50)
```

**2. Фільтр Савіцького-Голея:**
```
y_i = (1/M) Σ(j=-m to m) c_j * x_(i+j)
```
де M — нормалізуючий коефіцієнт, c_j — коефіцієнти фільтра

**3. RMS (Root Mean Square):**
```
RMS = √[(1/N) Σ(i=1 to N) x_i²]
```

**4. Тривісний RMSA:**
```
RMSA_3D = √(RMS_x² + RMS_y² + RMS_z²)
```

**5. Z-score:**
```
Z = (x - μ) / σ
```

### 7.2. Фізичний зміст

- **RMSA** — інтегральна характеристика інтенсивності вібрацій, що корелює з нерівністю дороги
- **IRI** — довжина вертикальних переміщень підвіски на одиницю довжини шляху
- **Співвідношення:** RMSA ≈ 0.25 × IRI (емпірична залежність для асфальтованих доріг)
