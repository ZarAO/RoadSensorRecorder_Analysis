## Проблеми, що були виявлені:

### 1. RMSA обчислювалось як 0.0
**Причина:** Високочастотний фільтр Баттерворта перетворював розріджені дані (з NaN) на нулі.

**Рішення:** Видалено застосування високочастотного фільтра до розріджених даних. Фільтрація тепер відбувається тільки в `compute_rmsa()` через фільтр Савіцького-Голея, який працює після заповнення пропусків.

### 2. Піки не виявлялись (0 піків)
**Причина:** Поріг 1.5 м/с² був занадто високим для каліброваних даних.

**Рішення:** Зменшено поріг до 0.5 м/с² в `main.py`.

### 3. Matplotlib не міг створити вікна
**Причина:** Проблема з Tcl/Tk backend при спробі створення інтерактивних графіків.

**Рішення:** Додано `matplotlib.use('Agg')` для використання non-interactive backend у `visualization.py`.

### 4. Калібрування повертало всі NaN
**Причина:** `rolling().mean()` без `min_periods` повертав NaN на розріджених даних.

**Рішення:** Додано `min_periods=1` до `rolling()` в функції `calibrate_accelerometer()`.

### 5. Видалення викидів перетворювало все на NaN
**Причина:** `remove_outliers()` обчислював статистику на даних з NaN.

**Рішення:** Оновлено функцію для обчислення статистики тільки на не-NaN значеннях.

### 6. Застарілий синтаксис pandas
**Причина:** `fillna(method='ffill')` застарів у pandas 2.x.

**Рішення:** Замінено на `.ffill().bfill()`.
