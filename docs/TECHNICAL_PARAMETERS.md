# Технічні параметри та константи для наукової публікації

## 1. Параметри калібрування

### 1.1. Компенсація гравітації
```python
GRAVITY_COMPENSATION_WINDOW = 50  # записів
```
**Обґрунтування:** Вікно 50 записів забезпечує баланс між згладжуванням гравітаційної компоненти та збереженням динамічних характеристик сигналу.

**Часовий інтервал (при частоті ~50 Гц):** ~1 секунда

## 2. Параметри фільтрації

### 2.1. Фільтр Савіцького-Голея
```python
SAVGOL_WINDOW_LENGTH = 11  # записів (має бути непарним)
SAVGOL_POLYORDER = 2       # порядок поліному
```

**Математичне обґрунтування:**
- Вікно 11 → фільтрує шуми з періодом < 0.22 с
- Поліном 2-го порядку → зберігає квадратичні тренди
- Фазове зміщення: відсутнє (симетричний фільтр)

### 2.2. Високочастотний фільтр Баттерворта
```python
HIGHPASS_CUTOFF = 0.5  # Гц
HIGHPASS_ORDER = 4     # порядок фільтра
SAMPLING_FREQUENCY = 50  # Гц (типова для смартфонів)
```

**Передавальна функція:**
```
|H(f)| = 1 / √(1 + (f_c/f)^(2n))
```
де:
- f_c = 0.5 Гц (частота зрізу)
- n = 4 (порядок)
- f = частота сигналу

**Частотна характеристика:**
- f < 0.5 Гц: ослаблення > 12 дБ/октаву
- f > 1.0 Гц: пропускання без спотворень

### 2.3. Фільтр викидів (Z-score)
```python
ZSCORE_THRESHOLD = 3.0  # кратність стандартного відхилення
```

**Статистичне обґрунтування:**
- 3σ охоплює 99.7% нормального розподілу
- Відхилення > 3σ вважається статистично значущим викидом
- Втрата даних: зазвичай < 1-3%

## 3. Параметри RMSA

### 3.1. Ковзне вікно для RMS
```python
RMS_WINDOW_SIZE = 10  # записів
```

**Часовий інтервал (при 50 Гц):** 0.2 секунди

**Просторовий інтервал (при швидкості 50 км/год):**
```
Δs = v × Δt = 13.9 м/с × 0.2 с ≈ 2.8 метра
```

### 3.2. Формула тривісного RMSA
```
RMSA_3D = √(RMS_x² + RMS_y² + RMS_z²)

де для кожної осі i ∈ {x, y, z}:
RMS_i = √[(1/N) Σ(j=1 to N) a_i,j²]
```

**Одиниці:** м/с² (метрів за секунду в квадраті)

**Фізичний зміст:** Інтегральна характеристика інтенсивності вібрацій у тривімірному просторі.

## 4. Класифікація якості доріг

### 4.1. Порогові значення RMSA
```python
EXCELLENT_THRESHOLD = 0.5   # м/с²
GOOD_THRESHOLD = 1.0        # м/с²
SATISFACTORY_THRESHOLD = 2.0  # м/с²
```

### 4.2. Відповідність IRI (International Roughness Index)
```
IRI ≈ 4.0 × RMSA  (емпірична залежність для асфальтованих доріг)
```

| Категорія | RMSA (м/с²) | IRI (м/км) | Стан покриття |
|-----------|-------------|------------|---------------|
| Відмінно | < 0.5 | < 2 | Нове/відремонтоване |
| Добре | 0.5-1.0 | 2-4 | Експлуатаційна норма |
| Задовільно | 1.0-2.0 | 4-8 | Потрібен ремонт |
| Погано | ≥ 2.0 | ≥ 8 | Аварійний стан |

**Джерело:** Адаптовано на основі ASTM E1926 та World Bank Guidelines

## 5. Сегментація дороги

### 5.1. Розмір сегмента
```python
SEGMENT_LENGTH = 30  # записів
```

**Просторова довжина сегмента (при 50 км/год, 50 Гц):**

**Обґрунтування:** 8-10 метрів — типова довжина сегмента для оцінки якості доріг згідно з IRI стандартами.

## 8. Математичні константи

### 8.1. Стандартне прискорення вільного падіння
```
g = 9.80665 м/с²  (стандартне значення ISO 80000-3)
```

**Примітка:** Реальне значення в Україні: 9.80-9.81 м/с² (залежить від широти)

### 8.2. Частота Найквіста
```
f_Nyquist = f_sampling / 2 = 50 / 2 = 25 Гц
```

**Теорема Котельникова:** Для коректної дискретизації сигналу максимальна частота сигналу має бути < f_Nyquist.

## 9. Точність вимірювань

### 9.1. Точність акселерометра

## 12. Формули для статті

### 12.1. Компенсація гравітації (LaTeX)
```latex
\vec{a}_{linear}(t) = \vec{a}_{measured}(t) - \frac{1}{N}\sum_{i=0}^{N-1}\vec{a}_{measured}(t-i)
```

### 12.2. Тривісний RMSA (LaTeX)
```latex
RMSA_{3D} = \sqrt{RMS_x^2 + RMS_y^2 + RMS_z^2}
```
де
```latex
RMS_i = \sqrt{\frac{1}{N}\sum_{j=1}^{N}a_{i,j}^2}, \quad i \in \{x, y, z\}
```

### 12.3. Z-score (LaTeX)
```latex
Z = \frac{|x - \mu|}{\sigma}
```

### 12.4. Фільтр Баттерворта (LaTeX)
```latex
|H(f)| = \frac{1}{\sqrt{1 + \left(\frac{f_c}{f}\right)^{2n}}}
```
