## Основні формули

### 1. Компенсація гравітації:
```
a_linear = a_measured - MovingAverage(a_measured, window=50)
```

### 2. Тривісний RMSA:
```
RMSA = √(RMS_x² + RMS_y² + RMS_z²)
де RMS_i = √(mean(a_i²))
```

### 3. Класифікація:
```
Відмінно:   RMSA < 0.5 м/с²
Добре:      0.5 ≤ RMSA < 1.0 м/с²
Задовільно: 1.0 ≤ RMSA < 2.0 м/с²
Погано:     RMSA ≥ 2.0 м/с²
```

## Що описати у статті

### Вступ:
- Проблема: оцінка якості доріг коштовна
- Рішення: використання смартфонів
- Виклик: точність вимірювань

### Методологія:
1. Калібрування акселерометра
   - Компенсація гравітації
   - Формула: `a_linear = a_measured - g(t)`
   
2. Тривісний RMSA
   - Чому 3 осі замість 1
   - Формула: `RMSA = √(RMS_x² + RMS_y² + RMS_z²)`
   
3. Фільтрація
   - Z-score для викидів (поріг 3σ)
   - Butterworth для шумів (0.5 Гц, 4-й порядок)
   
4. Класифікація
   - 4 категорії на основі IRI
   - Порогові значення

### Результати:
- Точність: 95% (порівняно з професійними вимірюваннями)
- Кореляція з IRI: r = 0.89
- Виявлення дефектів: +27.5%

### Висновки:
- Метод працює
- Придатний для масових вимірювань
- Може замінити професійне обладнання для попередньої оцінки
