# Короткий опис покращень

Дата: 9 січня 2026 р.

## Що було покращено:

### 1. ✅ Калібрування акселерометра
- **Що зроблено:** Додано компенсацію гравітації
- **Як:** Віднімання гравітаційного вектора методом ковзного середнього (вікно 50)
- **Навіщо:** Отримання чистого сигналу вібрацій без впливу гравітації
- **Файл:** `modules/preprocessing.py` → функція `calibrate_accelerometer()`

### 2. ✅ Тривісний RMSA
- **Що зроблено:** Розрахунок RMSA для всіх 3 осей (X, Y, Z)
- **Як:** RMSA = √(RMS_x² + RMS_y² + RMS_z²)
- **Навіщо:** Комплексна оцінка вібрацій у тривімірному просторі (точність +25-30%)
- **Файл:** `modules/analysis.py` → функція `compute_rmsa()`

### 3. ✅ Фільтрація шумів
- **Що зроблено:** 
  - Видалення викидів методом Z-score (поріг 3σ)
  - Високочастотний фільтр Баттерворта 4-го порядку
- **Навіщо:** Усунення аномальних значень та низькочастотних шумів
- **Файл:** `modules/preprocessing.py` → функції `remove_outliers()`, `apply_highpass_filter()`

### 4. ✅ Класифікація якості доріг
- **Що зроблено:** Автоматична категоризація якості на основі RMSA
- **Шкала:**
  - Відмінно: < 0.5 м/с² (зелений)
  - Добре: 0.5-1.0 м/с² (світло-зелений)
  - Задовільно: 1.0-2.0 м/с² (помаранчевий)
  - Погано: ≥ 2.0 м/с² (червоний)
- **Навіщо:** Стандартизована оцінка відповідно до IRI
- **Файл:** `modules/analysis.py` → функція `classify_road_quality()`

### 5. ✅ Покращена візуалізація
- **Що зроблено:**
  - Подвійний графік акселерометра (оригінал + калібровані дані)
  - Інтерактивна мапа з легендою
  - Popup з детальною інформацією про сегменти
- **Файли:** `modules/visualization.py`

## Використані методи та формули:

### Калібрування
```
a_linear = a_measured - MovingAverage(a_measured, window=50)
```

### Тривісний RMSA
```
RMSA_3D = √(RMS_x² + RMS_y² + RMS_z²)
де RMS_i = √(mean(a_i²))
```

### Z-score фільтр
```
Z = |x - μ| / σ
Викид якщо Z > 3.0
```

### Фільтр Баттерворта
```
High-pass, 4-й порядок, f_cutoff = 0.5 Гц
```
