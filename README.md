# RoadSensorRecorder - Аналіз якості дорожнього покриття 🛣️

Система аналізу якості дорожнього покриття на основі даних з сенсорів смартфона (акселерометр, гіроскоп, GPS).

## 🎯 Призначення

Проект призначений для оцінки стану доріг методом вимірювання вібрацій транспортного засобу через датчики смартфона. Результати відповідають міжнародному стандарту IRI (International Roughness Index).

## 🔬 Наукові основи

### Калібрування акселерометра

$$\vec{a}_{linear}(t) = \vec{a}_{measured}(t) - \frac{1}{N}\sum_{i=0}^{N-1}\vec{a}_{measured}(t-i)$$

### Тривісний RMSA

$$RMSA_{3D} = \sqrt{RMS_x^2 + RMS_y^2 + RMS_z^2}$$

де $RMS_i = \sqrt{\frac{1}{M}\sum_{j=1}^{M}a_{i,j}^2}$

### Класифікація якості

| Категорія | RMSA (м/с²) | IRI (м/км) | Колір |
|-----------|-------------|------------|-------|
| Відмінно | < 0.5 | < 2 | 🟢 Зелений |
| Добре | 0.5-1.0 | 2-4 | 🟢 Світло-зелений |
| Задовільно | 1.0-2.0 | 4-8 | 🟠 Помаранчевий |
| Погано | ≥ 2.0 | ≥ 8 | 🔴 Червоний |

## 📱 Формат вхідних даних

CSV файл з колонками:
```
Time,Type,X,Y,Z,Latitude,Longitude
```

**Типи записів:**
- `Accelerometer` — прискорення (м/с²)
- `Gyroscope` — кутова швидкість (рад/с)
- `Location` — GPS координати
